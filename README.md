# enterprise-semantics-visuals

> Enterprise-Semantics visual semantic assets: reproducible diagrams (conceptual, architecture, semantic maps, lifecycle, causal, comparative, application). PlantUML/Mermaid/SVG sources with PNG renders.

This repository holds the **source** of every diagram used across the program. Renders (PNG/SVG) are generated from the sources; never hand-edit a render.
